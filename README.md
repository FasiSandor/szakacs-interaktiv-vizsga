# Szakács Interaktív Vizsga

Interaktív, mobil-first gyakorlóapp szakács vizsgára készülő tanulóknak.

## Jelenlegi funkciók

- gyors gyakorlás 10 véletlen kérdéssel
- próbavizsga 16 kérdéssel
- feleletválasztós, többválasztós, igaz/hamis és számolós feladatok
- azonnali magyarázat gyakorló módban
- eredmény és hibák áttekintése
- véletlenszerű kérdéssorrend
- reszponzív mobil, tablet és asztali felület

## Következő fejlesztések

- nagy, adatbázis-alapú kérdésbank
- témakör szerinti célzott gyakorlás
- párosítás, sorrendezés és legördülős feladatok
- tanári kérdésbank-kezelő
- tanulói eredmények és gyenge pontok
- Supabase integráció
